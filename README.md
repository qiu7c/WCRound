# WCRound 微信圆角

独立的微信圆角调节插件，各类圆角支持单独开启和设置程度。

- 首页圆角，支持左右边距、卡片间距及合并置顶区域。
- 全局头像圆角，按头像尺寸调节比例。
- 聊天输入框与外工具栏圆角，分别设置半径。
- 朋友圈图片、视频、九宫格和相册缩略图圆角。
- 好友资料页朋友圈入口及视频号缩略图圆角。
- 表情面板、表情预览及聊天表情圆角。
- 聊天图片、视频的媒体容器圆角。
- 头像、输入栏和朋友圈圆角实时预览。

设置入口位于插件管理，未安装插件管理时显示在微信“我”页面。各类功能默认关闭，支持浅色与深色外观。与 WCGroups 同时使用时，首页圆角适配分组栏和设备横幅。

支持 JSON 配置导入与导出，设置界面采用圆角卡片和分组折叠。
